Whenever we have a google sheet filled with different URLs/websites/links used for different purposes, and want to check weather a link is working or giving a 404 error we have to go 
to every single link and check, this project solves that problem.
It goes through every single single link and gives us the result about how many links are working and how many are not.
We can later download the working(Active) links and the non working(Inactive) links as well.
